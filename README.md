# Gemeinsame Vorgaben der Organisation

Dieses Repository liefert die Vorgaben, die für alle Repositories der Organisation gelten:

- `PULL_REQUEST_TEMPLATE.md` — Vorlage für jeden Pull Request
- `.github/workflows/pr-pruefung.yml` — wiederverwendbare PR-Prüfung
- `.github/workflows/release.yml` — wiederverwendbarer Release-Lauf mit Changelog
- `workflow-templates/` — Startvorlage für neue Repositories
